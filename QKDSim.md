# Расчет углов QKDSim

`bb84.py`, `goks.py` и `b92.py` рассчитывают таблицы соответствующих протоколов по исходным углам. Общая модель находится в `qkd_angles.py`; держите эти файлы в одном каталоге. Каждая строка содержит базис, бит, четыре угла и интерпретаторы PDH/PDV для переноса в "Правила протокола".

## Запуск на NixOS

Из корня проекта:

```sh
cd hitech-cyber-security
nix-shell -p python3Packages.numpy
```

Дальнейшие команды выполняются в этой оболочке. На других системах нужен Python с NumPy.

## Таблицы протоколов

```sh
# BB84: углы Боба для базиса 0 и theta3 второго базиса.
python3 bb84.py --bob 65 35 --th3 100

# ГОКС: углы Боба для базиса 0, ожидаемого бита 0.
python3 goks.py --bob 48 78

# B92: углы Боба для ожидаемого бита 0.
python3 b92.py --bob 32 20
```

Скрипт рассчитывает остальные углы Алисы и Боба. Можно вводить свои дробные значения:

```sh
python3 goks.py --bob 13.27 71.83
python3 b92.py --bob 13.27 71.83
python3 bb84.py --bob 13.27 71.83 --th3 100
```

Если в BB84 заданы обе пары углов Боба, используйте `--b1`. Проверяется равное деление сигнала с допуском `1e-8` доли. Несовместимые базисы завершатся сообщением об ошибке; для автоматического расчета второго базиса задавайте только `--th3`:

```sh
python3 bb84.py --bob 0 0 --b1 22.5 0
```

Старые параметры `bb84 --b0`, `goks --b00` и `b92 --b0` сохранены. `--flip` в ГОКС/B92 выбирает второе направление построения состояний.

## Отдельные пластины

```sh
# Алиса по углам Боба, погасить PDH.
python3 qkd_angles.py alice --bob 65 35 --target h0

# Алиса с дополнительно фиксированным theta2.
python3 qkd_angles.py alice --bob 65 35 --theta2 5 --target h0

# Боб по углам Алисы, погасить PDV.
python3 qkd_angles.py bob --alice 20 5 --target v0

# Проверка заданных четырех углов.
python3 qkd_angles.py check 20 5 65 35
```

`h0` означает PDH=0, `v0` означает PDV=0. У `bob` можно зафиксировать theta4 через `--theta4`. Несовместимые ограничения дадут сообщение об отсутствии решения.

## Точность

Расчет выполняется без промежуточного округления. `--digits` задает от 1 до 12 знаков после точки, по умолчанию 6:

```sh
python3 bb84.py --bob 65 35 --th3 100 --digits 9
python3 goks.py --bob 48 78 --digits 1
python3 b92.py --bob 32 20 --digits 9 --json
```

Если поле QKDSim принимает только десятые доли градуса, задайте `--digits 1`. Матрица сигналов и максимальная ошибка проверяются для выведенных углов, с учетом округления.

В JSON `rows` содержит таблицу настроек. `pdh_matrix` содержит доли сигнала PDH от 0 до 1: строки соответствуют состояниям Алисы, столбцы - настройкам Боба в порядке `rows`. `max_error` - максимальное абсолютное отклонение доли PDH от идеальной матрицы протокола. Значение `0.0001` соответствует `0.01` процентного пункта. Интерпретатор PDV в ГОКС и B92 равен `X`.

Используется идеальная Jones-модель четырех пластин исходного скрипта, PDH+PDV=55639. Численная точность модели не является измеренной точностью установки.
